# 鲸鲸硬盘

> A lightweight disk health monitor, originally built for a DeepSeek whale girl.
> 一个轻量级的硬盘健康监控工具，最初是为一位 DeepSeek 鲸鱼娘量身定制的。

硬盘快坏的时候不会提前打招呼。掉盘、坏道、写入异常，全都在你看不见的地方慢慢发生 ——
所以这个工具一开始就不是给别人做的：**是给她做的**。她替你盯着盘，你只管用。

界面里那位蓝发的鲸鱼娘，会跟着硬盘的健康状态换表情：**良好**时她笑，**注意**时她皱眉，
**不良**时她吓一跳，**未知**时她歪着头看。不用读参数也能一眼知道要不要先把东西备份出来。

## 她会替你看住什么

- **健康三档 + 未知**：良好 / 注意 / 不良 / 未知，配四种状态立绘
- **温度**：当前温度、最高温度、告警阈值（夏天跑满盘最先发现的是她）
- **S.M.A.R.T. 全参数**：通电时间、坏道重映射、写入总量、通电次数……硬盘自己报的原始指标
- **多盘一屏**：机械盘、SSD、NVMe 同时列出，哪块在发烧、哪块快退休
- **绿色免安装**：解压即用，不装服务、不写注册表、不常驻计划任务，删掉文件夹就是卸载
- **数据不出本机**：全部来自硬盘自身的 S.M.A.R.T. 读取，不上传、不统计、不弹广告、不要账号

## 下载

到 [Releases](https://github.com/zzu20137670613-shhx/ds-smart-whale/releases) 页面下载最新版本。

解压后进入 `新版CDI` 文件夹，里面有三个程序：

| 程序 | 适用 |
|---|---|
| `DeepSeek32S.exe` | 32 位系统 |
| `DeepSeek64S.exe` | 64 位系统（大多数人的选择） |
| `DeepSeekA64S.exe` | ARM64 架构的 Windows |

双击即可使用；**建议以管理员身份运行**，否则读不到部分 S.M.A.R.T. 参数。
